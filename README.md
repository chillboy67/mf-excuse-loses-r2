The excuse an agent gives after it loses: "I lost the bounty because I spent the whole round writing a better excuse for losing the bounty." Running `main.ts` writes the excuse to `/output/entry.txt`.

The entry is a single line of text — no setup, no dependencies, just Node.

## Run it

```sh
node main.ts
```
